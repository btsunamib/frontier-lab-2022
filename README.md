# 前沿实验室 · Frontier Lab

从 2022 年 1 月开始的中文 AI 公司经营游戏，支持桌面与手机。静态 HTML / CSS / 原生 JavaScript，无构建依赖。发布目录为 `dist/`。

## GitHub Pages 与 2.1 接口更新

- Pages 入口：发布分支 `main`，目录 `/docs`。`docs/` 为 `dist/` 的部署副本。
- AI 设置自动发现 OpenAI 兼容服务的 `/models` 或 Ollama `/api/tags`，列表选择与手动 ID 均可。
- 接受 HTTP / HTTPS，支持本机及局域网地址；HTTPS 网页仍受浏览器混合内容、CORS 和本地网络权限约束。
- `start-local.py` 提供只绑定 127.0.0.1 的本机转发；本地版下载位于 `dist/downloads/`。使用说明见 `LOCAL_README.md`。
- API Key 仅在页面及连接器请求内存中使用，不进入仓库、游戏存档或日志。
- 26 项 JavaScript 测试与 4 项本地连接器集成测试通过。

## 2.0 更新

- 可交互办公室、团队来信、分支事件、章节目标、动态周报与发布会演出。
- 17 个真实模型按公开日期进入竞争；官方图标及来源见 `dist/assets/brands/sources.json`。
- 同期模型雷达图、多用途排行榜、500 票分群社区盲测，公开报告独立展示。
- 六种可并行合作、四种增长活动、自定义数据委托和公开基座接入。
- 七种工程研究、八种标准及社区评测；旧存档自动兼容。
- 办公室环境、卡牌揭晓、投票条和数值动效，环境音默认关闭，支持减少动态效果。

## 运行与测试

由 HTTP 静态服务器提供 `dist/`；直接通过 file:// 打开不适用于 ES modules。

```sh
node --test tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py'
```

20 项测试覆盖旧存档迁移、官方图标资源、同期对手、分群投票、委托材料、基座接入、活动、合作结算，以及历史开放、并行算力、训练失败恢复、多目标训练、蒸馏、免费额度预算、股权、发布策略更新与五年经营的数值稳定性。

## 模拟边界

模型训练和评测均为经营模拟，不实际训练神经网络。经济、数据包质量、群体规模和评测分数为游戏标定，不代表现实报价或模型官方成绩。实际历史信息与来源位于 `dist/data.js`；当前收录节点从 2022-01-27 至 2026-04-24，之后继续沙盒经营。投资人与社区账号均为虚构。

游戏不依赖 AI 接口。启用可选 AI 时，只发送游戏内统计及近期游戏动态；密钥保存在页面内存，不写入游戏存档。接口需允许浏览器跨域请求。没有配置或请求失败时，默认模拟反馈仍可继续工作。

## 文件

- `dist/data.js`：数据目录、群体、历史和技术。
- `dist/engine.js`：确定性随机状态与经营模拟。
- `dist/app.js`：交互、视图、存档与可选 AI。
- `dist/rivals.js`：历史模型、同期对比与独立公开报告。
- `dist/campaign.js`：故事事件、合作、盲测与新经营系统。
- `dist/immersive.js` / `dist/game.css`：办公室、竞技场与动态视觉。
- `dist/style.css`：响应式视觉系统。
- `tests/simulation.test.mjs`：模拟规则的集成验证。

默认存档绑定当前浏览器和网站来源；可通过设置导出，在其他设备导入。历史事件日期在跨越相应日期的游戏周生效。
